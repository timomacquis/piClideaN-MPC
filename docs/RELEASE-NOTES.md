# Version 1.3.1

- Add per-step GATE locks using the existing upper-right control in EDIT. LINE GATE remains the default; steps without a lock inherit it.
- Keep HOLD priority and apply the effective GATE duration to each ratchet repeat. A short or One Shot sample may not reveal MIDI note-length changes; use a target that responds to Note Off.
- Highlight the entire expression-control box in purple when the selected step has a lock: GATE, velocity, probability, ratchet and decay.
- Limit patterns generated by RAND and Rd ALL to 75% active steps, rounded down. Manual note editing, ratchet repeats and independent LFO triggers are unaffected.
- Preserve unselected parameters in selective RAND. If they make the density limit impossible, leave the lane unchanged. Rd ALL continues to preserve mute states and pitches.
- Add CONFIG COUNT-IN: OFF (default), RECORD, or RECORD + PLAY, to match the host count-in setting.
- Preserve all 4,096 parameter keys and indices. Older projects load with per-step GATE inheritance. Newly saved projects include GATE data and cannot be opened by 1.3.0; keep the original project before upgrading.
- Provide separate Gen1 ARM32 and Gen2 ARM64 packages, retaining the Live III small-image workaround exclusively in the Gen2 skin.

## Standard catalog distribution

Both 1.3.1 installation downloads use the unmodified official Open MPC installer/uninstaller and standard manifest. They replace the former custom portable packages on this release. Engine and native skin bytes are unchanged. The standard ZIPs pass catalog checks and isolated installation/reinstallation/removal simulations; device installation of these exact standard ZIPs and a device CPU benchmark remain pending.

## Validation

The user tried candidate.1 on Akai Force and accepted the interface and other observed changes. The audible GATE effect was not assessed with a sustained sound: the test used short drum hits. Count-in behavior on hardware remains to be confirmed. Offline checks cover scheduled Note On/Off durations, HOLD, ratchet, project state, count-in and density limits.

The newly rebuilt Gen2 package is not device-validated. Thomas Phillips's earlier Live III test concerned the original 1.2.4 port; it is not a validation of 1.3.1. No new device CPU benchmark, Verified catalog status or universal crackle-free guarantee is claimed.

# Version 1.3.0

- Add Random Walk, Random Loop and Bounce to the eleven-shape MOD palette.
- Add pulse width, random step size, loop evolution, gravity and restitution controls.
- Chain either LFO into the other’s rate, depth or offset. Preserve the existing NOTE ON and threshold behavior.
- Cache static waveform previews and compute them on a dedicated background worker.
- Reduce queued display notification bursts and remove unused preview notifications.
- Share identical image assets and streamline the miniature steps on both track pages.
- Correct native miniature frame slicing and retain note, custom-value and playhead colours.
- Update the illustrated user manual.

Musical operation and interface improvements were validated by the user on Akai Force. Crackles previously reported during interaction were no longer observed in the tested setup. CPU and effects loads vary by project; no universal performance guarantee is made.

Projects save the PICN7 state format; PICN6 states can be loaded. Earlier plugin versions cannot load the new state format. Parameter indices remain unchanged.
