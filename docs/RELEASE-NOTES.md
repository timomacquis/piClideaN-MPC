# πClideaN 1.3.4

- New coherent skin, clearer values and contextual physical Q-Links.
- Seven native presets, including INIT and musical starting points.
- Per-line rhythmic A/B variants and COPY A → B.
- Guided ALTER: choose STEPS, HITS, ROTATE and DIVISION, with LIGHT / MEDIUM / FREE strength.
- Rdm 8 generates complementary patterns on lanes 01–08, preserving their notes and MUTE states. Lanes 09–16 remain untouched.
- Compact, attributed Groove MIDI Dataset statistics guide rhythmic preferences; no neural model or raw MIDI corpus runs on the device.
- Separate VAR and two-stage RAND buttons; ½ and ×2 share one slot. No long press required.
- Cached graphics, bounded UI notifications and background candidate search.

Generated patterns remain capped at 75% active steps. A/B changes geometry and step expression; notes, LINE settings and modulation remain shared.

PICN8 state preserves all 4096 parameter indices and reads older PICN1–7 states. Older binaries cannot load PICN8: keep original project copies.

Gen1 / Force and Gen2 ARM64 packages are provided. The author validated the Gen1 candidate in a musical session on Force OS 3.10.0.49. Gen2 hardware and an exact-release install/uninstall cycle are not newly qualified.

# Version 1.3.2

- Preserve independent lane cycles across host transport loop boundaries. A 10-step lane now continues with step 05 after a 64-step host loop instead of restarting at step 01.
- Keep MIDI scheduling, playheads, traversal modes and automatic rotation on the same continuous musical timeline.
- Preserve GATE tails and ratchet/modulation latches across normal loop returns. Explicit RESET PHASE, transport seeks and Stop/Play remain separate actions.
- No parameter-index or project-state format changes.

## Validation

The fix was accepted by Greg on Akai Force, MPC OS 3.10.0.49, as 1.3.2-candidate.1. Offline sanitized transport tests compare looped and uninterrupted playback, including MIDI timestamps, 10/7/12/16-step lanes, nonzero loop starts, traversal modes, rotation, ratchets, HOLD and LFO modulation/NOTE ON. Existing regression tests also pass.

Separate Gen1 ARMv7 and Gen2 AArch64 packages are provided. This release has not been tested on Gen2 hardware; Gen1 validation does not qualify Gen2.

# Version 1.3.1

- Add per-step GATE locks using the existing upper-right control in EDIT. LINE GATE remains the default; steps without a lock inherit it.
- Keep HOLD priority and apply the effective GATE duration to each ratchet repeat. A short or One Shot sample may not reveal MIDI note-length changes; use a target that responds to Note Off.
- Highlight the entire expression-control box in purple when the selected step has a lock: GATE, velocity, probability, ratchet and decay.
- Limit patterns generated by RAND and Rd ALL to 75% active steps, rounded down. Manual note editing, ratchet repeats and independent LFO triggers are unaffected.
- Preserve unselected parameters in selective RAND. If they make the density limit impossible, leave the lane unchanged. Rd ALL continues to preserve mute states and pitches.
- Add CONFIG COUNT-IN: OFF (default), RECORD, or RECORD + PLAY, to match the host count-in setting.
- Preserve all 4,096 parameter keys and indices. Older projects load with per-step GATE inheritance. Newly saved projects include GATE data and cannot be opened by 1.3.0; keep the original project before upgrading.
- Provide separate Gen1 ARM32 and Gen2 ARM64 packages, retaining the Live III small-image workaround exclusively in the Gen2 skin.

## Standard catalog distribution

Both 1.3.1 installation downloads use the unmodified official Open MPC installer/uninstaller and standard manifest. They replace the former custom portable packages on this release. Engine and native skin bytes are unchanged. The standard ZIPs pass catalog checks and isolated installation/reinstallation/removal simulations; device installation/removal of these exact standard ZIPs remains pending.

## Validation

The user tried candidate.1 on Akai Force and accepted the interface and other observed changes. The audible GATE effect was not assessed with a sustained sound: the test used short drum hits. Count-in behavior on hardware remains to be confirmed. Offline checks cover scheduled Note On/Off durations, HOLD, ratchet, project state, count-in and density limits.

The newly rebuilt Gen2 package is not device-validated. Thomas Phillips's earlier Live III test concerned the original 1.2.4 port; it is not a validation of 1.3.1. No Gen2 CPU result, Verified catalog status or universal crackle-free guarantee is claimed.

# Version 1.3.0

- Add Random Walk, Random Loop and Bounce to the eleven-shape MOD palette.
- Add pulse width, random step size, loop evolution, gravity and restitution controls.
- Chain either LFO into the other’s rate, depth or offset. Preserve the existing NOTE ON and threshold behavior.
- Cache static waveform previews and compute them on a dedicated background worker.
- Reduce queued display notification bursts and remove unused preview notifications.
- Share identical image assets and streamline the miniature steps on both track pages.
- Correct native miniature frame slicing and retain note, custom-value and playhead colours.
- Update the illustrated user manual.

Musical operation and interface improvements were validated by the user on Akai Force. Crackles previously reported during interaction were no longer observed in the tested setup. CPU and effects loads vary by project; no universal performance guarantee is made.

Projects save the PICN7 state format; PICN6 states can be loaded. Earlier plugin versions cannot load the new state format. Parameter indices remain unchanged.
