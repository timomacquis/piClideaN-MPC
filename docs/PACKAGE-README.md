# πClideaN — 1.3.5-candidate.3

A sixteen-line MIDI-only sequencer with Euclidean rhythms, per-step expression, polymetric cycles, scales and dual-LFO modulation.

This local candidate adds guided ALTER, per-line A/B and coordinated **I RdM 8** generation for lines 01–08. It retains the five-page skin, contextual Q-Links and seven native factory programs.

See [candidate behaviour and limitations](docs/CANDIDATE-1.3.5.md), the [English manual](docs/USER-MANUAL.md) and the [French manual](docs/MODE-EMPLOI.md).

Not installed or published. Hardware validation remains pending, especially the native RAND press/release gesture. Preserve original project copies before evaluation: older binaries cannot read the new A/B state extension.

## Groove-derived preferences

Candidate.2 adds 457 bytes of offline-extracted GMD statistics to guide spacing, compatible metric phases, density sampling and pair overlaps. No raw dataset or neural runtime is embedded. Same interface and safeguards. [Method, attribution and limits](GROOVE-STATISTICS.md).
